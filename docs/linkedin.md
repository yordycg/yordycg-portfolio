## 2. Guía paso a paso — escritorio

La UI de LinkedIn cambia etiquetas. Estas son las rutas actuales (2026) y su
alternativa si no aparecen.

1. Iniciar sesión y entrar al perfil:
   - `Me` → `View Profile`.
2. Editar la introducción:
   - Pencil del bloque superior → `Edit intro`.
   - Actualizar headline, cargo actual, ubicación `Chile`, industria
     `Desarrollo de software` y contacto.
3. Editar `About`:
   - Pencil de la sección o `Add profile section` → `Core` → `Add about`.
4. Experiencia:
   - `Add profile section` → `Core` → `Add position`.
   - O `+` junto a `Experience`.
   - Editar la práctica MPM y las entradas de arquitectura.
5. Educación:
   - `Add profile section` → `Recommended` → `Add education`.
   - Si no aparece, `+` en la sección `Education`.
6. Certificaciones:
   - `Add profile section` → `Background` → `Add licenses & certifications`.
7. Habilidades:
   - `Add profile section` → `Core` → `Add skills`.
   - O `+` en `Skills`.
8. Sitio web:
   - `Contact info` → editar el sitio web.
9. Disponibilidad:
   - Botón `Open to` → `Finding a new job`.
   - Puestos: `Desarrollador Backend`, `Backend Developer`, `Python Developer`,
     `Django Developer`.
   - Ubicación: remoto; disponibilidad inmediata/full-time dic–feb.

## 3. Guía paso a paso — móvil

1. Foto de perfil → `View profile`.
2. Icono de edición del bloque de introducción → headline y datos.
3. `Add section` → `Core` → `Add position` / `Add skills`.
4. Sección `Education` → `+` → `Add education`.
5. Sección `Licenses & certifications` → `+`.
6. `Open to` → configurar búsqueda remota.

Si una etiqueta no coincide, buscar la sección por nombre (`Experience`,
`Education`, `Skills`) y usar el `+` o el lápiz.
