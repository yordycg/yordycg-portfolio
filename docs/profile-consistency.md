detalle. No deben contradecirse.

## Reglas

- **Portfolio:** narrativa curada para el rol objetivo. No menciona el rubro
  anterior ni el teléfono.
- **CV:** documento de selección. Incluye historial completo, una línea neutra
  del rubro anterior y el teléfono.
- **LinkedIn:** registro profesional. Conserva los puestos reales, pero sin
  descripciones que desvíen la atención del backend.
- **Fechas, cargos y stack:** deben coincidir entre las tres superficies.
- **Keywords:** solo se publica lo que pasa la prueba de defensa (D14).
- **Idioma:** el inglés no se publica hasta poder sostener una entrevista
  técnica (D7).

## Fuentes

- Sitio: `docs/content.md` y `src/index.html`.

- LinkedIn: `docs/linkedin.md`.

Si cambia una fecha, un stack o una disponibilidad, actualizar las tres
superficies en la misma sesión.
